# Vishenka Medical Server

Клиент-серверный комплекс для ведения карт пациентов, автоматического анализа
жалоб с помощью языковой модели и сквозного шифрования переписки медицинского
персонала.

Проект не вводит новых криптографических или ИИ-методов. Его ценность — в
интеграции готовых технологий: Signal Protocol, локальная LLM через Ollama и
реляционная база карт пациентов объединены в одну систему так, что переписка
врачей недоступна серверу, а запрос к модели не содержит идентифицирующих
данных пациента.

## Возможности

- Регистрация и поиск пациента по СНИЛС с проверкой контрольного числа.
- Хранение карт посещений (название, описание, заметка врача, признак важности).
- Автоматический анализ жалоб локальной моделью qwen2.5:14b с учётом истории
  болезней пациента.
- Сквозное шифрование переписки на Signal Protocol (X3DH + Double Ratchet).
- Офлайн-доставка зашифрованных сообщений.
- Формирование текстового документа посещения по шаблону.

## Архитектура

Комплекс состоит из четырёх независимых компонентов. У каждой подсистемы своя
база данных и свой сетевой порт, поэтому сбой одного модуля не затрагивает
остальные.

| Модуль                   | Порт | Назначение                                | База данных |
| `medical-server`         | 6667 | карты пациентов, анализ жалоб             | CockroachDB :5432 |
| `main-server`            | 7006 | выдача адреса мессенджер-сервера по ключу | PostgreSQL :5433 |
| `local-messenger-server` | 7002 | E2EE-мессенджер (Signal)                  | PostgreSQL :5434 |
| `client`                 |  -—  | Swing-клиент                              | SQCipher (локально) |
